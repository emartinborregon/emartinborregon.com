# emartinborregon.com

Web personal de Eduard Martín-Borregón, en español, inglés y catalán. HTML y CSS estáticos, sin dependencias ni paso de compilación.

- `index.html`, `ia.html`, `referencias.html`: español (raíz).
- `en/`: inglés. `ca/`: catalán.
- `style.css`: estilos compartidos.
- `images/`: retrato, fotos (Flickr del autor, CC BY-NC-SA) y miniaturas de video.
- `sitemap.xml`, `robots.txt`, `llms.txt`: buscadores y asistentes de IA.

Para verla en local basta con abrir `index.html` en el navegador.
